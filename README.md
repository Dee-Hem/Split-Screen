# Split-Screen Launcher

A lightweight Android launcher designed to make multitasking faster and more accessible by putting your apps and split-screen workflow closer to you.

Instead of constantly switching between apps, Split-Screen Launcher provides a simple way to launch apps with multitasking in mind.

## ✨ Features

* 🚀 **Quick App Launching** — Launch your frequently used apps without unnecessary navigation.
* 🪟 **Split-Screen Focused** — Built around Android's multitasking capabilities.
* ⚡ **Lightweight & Fast** — Designed to stay simple without adding unnecessary overhead.
* 🎨 **Clean Interface** — A straightforward launcher experience focused on functionality.
* 📱 **Android Native** — Built specifically for Android devices.
* 🔧 **Customizable Workflow** — Organize your launcher experience around the way you multitask.

## 🛠️ Tech Stack

* **Language:** Kotlin
* **Platform:** Android
* **Minimum SDK:** 24
* **Target SDK:** 36
* **UI:** Jetpack Compose
* **Build System:** Gradle

## 🎯 Why Split-Screen Launcher?

Android already provides powerful multitasking capabilities, but getting into a productive split-screen workflow can still involve several steps.

Split-Screen Launcher explores a simpler approach: **make multitasking a first-class part of the launcher experience.**

The project was built as both a practical Android application and an exploration of how small changes to the way we launch apps can improve everyday workflows.

## 🚀 Getting Started

### Prerequisites

* Android Studio
* Android SDK
* Android device or emulator running Android 7.0 (API 24) or later

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Dee-Hem/Split-Screen.git
```

2. Open the project in **Android Studio**.

3. Allow Gradle to sync and download the required dependencies.

4. Connect an Android device or start an emulator.

5. Build and run the application.
