# Splitz

![License](https://img.shields.io/github/license/Dee-Hem/Split-Screen)
![Latest Release](https://img.shields.io/github/v/release/Dee-Hem/Split-Screen)

**Splitz** is a lightweight Android app built with Jetpack Compose that allows you to launch and manage split-screen app pairs with a single tap.

## Features
- **App Pairing:** Launch two apps side-by-side automatically.
- **Shortcuts & Categories:** Group and categorize shortcuts on your home screen.
- **Reliable Service:** Uses live binder verification and auto-recovery notifications to keep the accessibility service active.
- **Privacy-Focused & Open Source:** Free software under the GPL-3.0 license.

## Installation
Download the latest `app-release.apk` from the [Releases](https://github.com/Dee-Hem/Split-Screen/releases) page.

## Building from Source
git clone [https://github.com/Dee-Hem/Split-Screen.git](https://github.com/Dee-Hem/Split-Screen.git)
cd Split-Screen
./gradlew assembleRelease
